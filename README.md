# ⛏️ Add-ons para Minecraft Bedrock

Add-ons para Minecraft Bedrock Edition. Cada uno va en su carpeta y se instala con doble clic en su archivo `.mcaddon`.

| Add-on | Qué hace | Descargar |
|---|---|---|
| 🎒 [**Backpack Pro**](backpack-pro/) | Mochilas con mejoras (horno, imán, tanques, cultivo, música…) y un almacenamiento que **no pierde tus cosas**. Inspirado en Sophisticated Backpacks de Java. | [Backpack Pro.mcaddon](backpack-pro/Backpack%20Pro.mcaddon) |
